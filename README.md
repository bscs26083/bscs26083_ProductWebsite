# bscs26083_ProductWebsite

LiviesHq is a three page Olivia Rodrigo inspired merchandise website designed with a purple-themed aesthetic. The website includes a Home page, Products page, and an About Us page; all connected through a navigation bar, and styled using a single CSS file.

The Products page displays five different merchandise items with their images, prices, availability, and descriptions. The Contact page provides contact information and links to social media platforms. The website uses different shades of purple, rounded buttons, hover effects, and decorative fonts to create a cohesive Olivia Rodrigo inspired design.
